# Ungerrymander America

A website project dedicated to providing information and resources about gerrymandering in the United States and efforts to promote fair redistricting.

## About

Gerrymandering is the practice of manipulating electoral district boundaries to favor certain political parties or groups. This project aims to educate the public about:

- What gerrymandering is and how it affects democracy
- Current gerrymandering issues across US states
- Redistricting reform efforts and fair map initiatives
- Resources for civic engagement and advocacy
